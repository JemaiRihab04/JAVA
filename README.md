## 🎯 Objectif du projet

Ce mini-projet a été développé durant les *7 premières semaines du cours de Java*, dans le but d’apprendre et de pratiquer les bases de la *programmation orientée objet (POO)*.

Les principaux objectifs étaient de :
- Créer et manipuler des *classes, objets, attributs et méthodes*
- Mettre en œuvre les concepts d’**encapsulation, héritage et polymorphisme**
- Gérer des *exceptions personnalisées* (ZooFullException, InvalidAgeException)
- Organiser le code dans des *packages structurés*
- Appliquer les bonnes pratiques de développement Java

---

## 🐾 Fonctionnalités principales

- 🦓 Création d’animaux (Animal, Aquatique, Terrestre, Pinguin)
- 🧩 Ajout d’animaux dans un *zoo* limité en capacité
- 🚫 Déclenchement d’une exception si le zoo est plein (ZooFullException)
- ⚠️ Vérification de l’âge des animaux (InvalidAgeException)
- 🔍 Recherche d’un animal par nom ou famille
- 📊 Affichage du nombre total d’animaux après chaque ajout
